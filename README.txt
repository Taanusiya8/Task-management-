TASK MANAGER APP - PART 3

Part 3 adds the remaining major frontend modules:
- Calendar
- View tasks by date
- Add task from calendar
- Reports & Progress
- Completion percentage
- Pending/completed/overdue counts
- Weekly progress
- Profile management
- Notification setting
- Theme setting
- Change password
- Logout
- Basic upcoming/overdue notification checking

The project includes Parts 1 and 2 as well.

HOW TO RUN:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open frontend/index.html using Live Server.
4. Register/login.
5. Test Dashboard, Tasks, Calendar, Reports and Profile.

IMPORTANT:
This is still a frontend prototype using localStorage.
For the final college project, the next stage should connect the application
to a Python backend and SQLite/MySQL database, with secure password handling.
